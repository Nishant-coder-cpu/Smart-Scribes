# Setup notes
# 1. Use a Python 3.10+ virtual environment (3.12 recommended).
# 2. Install PyTorch with CUDA first:
#      pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
# 3. Install ffmpeg and either add it to PATH or set FFMPEG_PATH in .env
#    (Python_Codes/config.py auto-detects it - no more editing source files).
# 4. Copy Python_Codes/.env.example to Python_Codes/.env and fill in the values.
# 5. all_data.txt is the fused audio/video/text output generated by the pipeline.
# 6. The final JSON sent to the frontend is merged_all_in_one_gemini.json.
